# asteroids-game

Shoot asteroids and enemies for points!              
Demo Link:
https://web-4-eight-blush.vercel.app/          

Symbols:                
Green Arrow/Spaceship = Your Craft            
Red/Gray Arrow/Spaceship = Enemy Craft (Shoot for +10 Points!)            
Gray Circle = Asteroid (Shoot to destroy for +1 Point!)          
Red Lines = Direction Vectors          
Blue Line = Your Momentum Vector        
White Circle = Enemy Detection Range            

Controls:          
LEFT / A   = Rotate left        
RIGHT / D  = Rotate right          
UP / W     = Apply thrust          
SPACE      = Fire missile
